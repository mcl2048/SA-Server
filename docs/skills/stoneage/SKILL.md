# StoneAge 素材与动画

用于StoneAge已有角色素材、用户多视图原画与原生动作的制作／修整；以用户当前角色设计与任务约束为准。不要因调用本skill扩大到战斗数值、UI重构或生产部署。

## 先看实际问题

读取当前任务和生成器、图集清单、客户端加载及绘制路径。先查看用户截图，确定宠物、方向、动作和关键帧；与已安装及旧发行图包对照。旧包残留、旧运行进程、外部client路径或浏览器资源选择可能使修正未生效，不能只凭本地文件存在宣称线上已修复。

优先研究原生同体型宠物的待机／跑步／攻击帧，例如虎类金格萨贝鲁、体量参照洛奇安。参照地面足点、投影、节奏与体积感；不同姿势的外框不代表相同骨架，不能生搬其每向宽高。

## 比例与落点

- 原画八向按解剖方向逐一映射；左右爪／武器属角色身体一侧，不为凑方向随意镜像。
- 每个方向只用单一缩放比例。另核对转向前后身体高度、躯干厚度、头部和足底；“最长边装进同一外框”会让身体长、尾巴长的侧面整体缩水。
- 按主体和足底定义尺度与锚点，排除尾尖／爪尖／武器对中心的干扰。容许透视自然缩短，避免强行把所有方向的可见外框变成同一比例。
- RGBA裁透明边之后同步补偿锚点；重建逻辑帧应与裁切前像素及世界位置一致。画布应容纳最长方向及动作极值，而非缩小宠物以避免裁切。
- 地面阴影是角色必要的一层。陆地角色有接触核心，漂浮角色在地面有分离投影；身体跳跃、受击转动或升空时，影子保持在地面，可随高度缩小／减淡，不随身体一起飞或旋转。

## 动作质量

跑步需要蹬地、屈膝收腿、前伸落脚、腾空与重心起伏；四根直腿交替摆动不足以表现奔跑。分层后单独查看躯干和四肢：躯干不能残留膝以下旧腿，肢体不能混入邻腿碎片。保留关节纹理与前后遮挡，支撑阶段足底不滑；身体俯仰、脊背和尾巴与步态一致。参考原生跑姿后检查循环接缝，不能仅验证帧不同。

攻击按角色设定做完整预备、发力、命中、收势；左爪／武器移动跟随正确关节，红痕等特效对应命中阶段。原生战斗通常负责出击与回位，素材不要重复烘焙世界位移。保持图号、动作号、方向、事件标记和时长兼容，除非当前任务明确要改。

## 验收与升级

阅读[验证与发行细则](references/validation-and-packaging.md)完成实际战场、逐向动作及增量安装验证。几何检查只能证明几何，不代表艺术质量完美。用实际截图／连续动画审阅头身、脚底、影子和关节，报告清楚证据与限制。

本skill不授予提交、推送、删除、停服或向外部服务写入的权限；按用户本轮及既有会话授权执行。用户已授权清理旧素材时，先校验并安装新包、验证完整后再清理已识别旧包；未知或修改内容保留并明确报告，不引入反复确认流程。

若当前任务还涉及导航、自动／离线挂机或合击播放，阅读[自动化与导航联调](references/automation-and-navigation.md)，核对暂停恢复、原生输入、服务端策略与事件顺序。

若当前任务涉及宠物商店、仓库、培养或战后经验，阅读[宠物寄放与培养](references/pet-storage-training.md)。只在任务要求时修改这些业务，不因素材工作扩展数值规则。
