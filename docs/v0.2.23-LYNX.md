# v0.2.23-LYNX · 高等级经验与传送导航

SA-1121-01修复火城130–140级吉比、泪之海及所有同根因自动经验敌人的零经验。完整恢复原版1–200级表，旧1–100级每一项保留；200级以后按最后增量55/级延伸，是本项目兼容策略。自动奖励饱和至32位上限；显式零经验不因等级差被提升为1。真实数据2,984条敌人、13,244个实际自动等级点均已审计。人物、出战宠、骑宠、培养、团队、胜败与退出规则沿用原结算入口。

小地图支持同图warp与经过相邻图返回原图另一片区域的两段通路。泪之海817宝箱路线经过(144,25)→(143,34)；尼克斯702从(388,10)到城内NPC可经703返回。普通A*失败才启用显式传送图的分帧Dijkstra；每段精确确认服务端楼层与落点。不能越过任务、条件、随机或对话传送，也不提供任意多层世界寻路。手动输入、新目标、锁定／跟随、普通战斗取消旧路线，快速战斗按既有规则暂停恢复。

## 安装

保留数据库与本地配置，正常SIGTERM存档停服后替换bin/saserver；使用外部client目录时同步本版本client/dist，重启并刷新浏览器。内嵌客户端已随ELF更新。没有数据库结构迁移或新增素材；现有update独立素材补丁仍包含在完整ZIP内，无需安装空素材补丁。配置经验倍率仍按现有值执行。

最新Linux AMD64静态ELF、SHA-256及完整ZIP在bin/。源码、客户端、最终二进制、HTTP实际字节和ZIP内容由[发行核验](../Report/SA-1121-01/release.json)关联。
