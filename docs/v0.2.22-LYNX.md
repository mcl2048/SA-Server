# v0.2.22-LYNX · 当前场景 NPC 与地图导航

v0.2.22-LYNX（SA-1115-04）加固小地图寻路并增加“NPC”页：只显示角色当前所在楼层的可见、有名、界内人物；不汇总整座洞窟、世界或历史区域。地图窗口显示时每5秒按需刷新，失联10秒后有界重试，保留上次快照；换层释放旧人物，迟到响应不恢复旧场景。真实资源当前单层最多100位NPC，包含地点目录的最大完整响应14030字节，阿布洞窟一层仅237字节；这些是本批资源快照测量。移动巴士／飞机显示最近快照坐标，不提供预测追踪。

NPC点击优先走到准确可通行坐标；人物位于墙／传送点时，选择可达的相邻普通格并明确显示实际停靠坐标，不自动对话、不误踩入口。地点、NPC及历史区域名称统一12px完整换行，按实际行高分页，保留完整触屏／可访问标签。普通地面点击与方向输入立即替换地图路线。

大地图A*每256个节点扩展主动让出一帧，长绕路／不可达规划可取消；仍以每步1和Chebyshev启发式选最短已知可达路径，未知格、墙角、非目标传送点规则保留。地图加载30秒无进展会明确取消并提示重试；快速战斗暂停恢复沿用。静态地点按World生命周期按需缓存，当前层重复目录请求分配由143次降至12次，动态NPC仍实时读取；全资源核对1206层／3309地点／4981物理入口／5002入口目的地组合。此处计数不能推断仅对话／脚本传送的地点也能自动跨越。

本批证据与限制见 [SA-1115-04验收](../Report/SA-1115-04/ACCEPTANCE.md) 和 [可视报告](../Report/SA-1115-04/index.html)。最终静态Linux AMD64及匹配ZIP位于bin/，未新增Assets，沿用既有独立素材补丁。移动验证为真实Chromium的触屏／视口模拟，未认证实体Android/iOS/Safari，未重启或部署生产实例。
