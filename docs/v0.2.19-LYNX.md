# v0.2.19-LYNX · 导航、战斗策略、合击与举炮动作

本轮基线为6b5cfde / v0.2.18-LYNX，任务SA-1115-01。具体测试、浏览器与发行摘要见 `Report/SA-1115-01/`。

## 使用变化

快速战斗开始暂停导航，保留目的地；结束后恢复寻路与行走。普通战斗按原交互清路线。地图支持输入精确X/Y坐标并点击“到目的地”，拒绝非法、跨楼层或越界坐标，继续使用现有阻挡检测与路径规划。

“战斗设定 → 基本”新增默认关闭的“自动逃跑”和“自动丢弃”。前者在自动／快速战斗优先逃跑，同场收到三次实际失败后转入通常策略；任务／头目／禁止逃跑地图和决斗遵循原有限制。后者输入关键字如 `石龟 | 蕨`，按名字字面包含、忽略空段，在日常与战后丢弃背包匹配物品，无需二次确认。关闭时隐藏输入框；设置仍按角色独立保存。旧“自动丢肉”保留兼容。

耐久力与气力均按“恢复比例”判断；恢复选择优先肉、再药物、最后可用精灵。气力恢复也支持没有恢复精灵的情况，原气力不足以施放恢复精灵时补气路径保留。

合击参考原作 `ComboCheck` / `BATTLE_Combo`：行动顺序由敏捷与随机因素决定，连续相邻、同阵营、同目标的普通近战攻击者有概率共同出击。玩家／宠物首个触发概率50%，怪物20%；无固定敏捷差、无额外1.2或1.5伤害倍率。普通技能、远程、异常／已离场对象不混入。协议新增`coattack`分组，和同一角色的`combo`连击分离；客户端同时接近、出击、回位，保持服务端HP结算顺序。

雷萨利朵使用右侧火炮手臂按肩关节抬臂、瞄准、开炮、收势；炮焰跟随实际炮口。图号、宠物编号与动作时序保持兼容，新目录为`assets/extensions/lisarido-v3`。
