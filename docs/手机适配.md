# v0.2.6-LYNX 手机适配

本文保留 v0.2.6 的适配、构建和验收记录。当前版本为 [v0.2.8-LYNX](v0.2.8-LYNX.md)，包含四只机械伙伴；完整4:3登录封面、PNG发布入口、服务端挂机与恢复行为见 [整合功能说明](v0.2.7-LYNX.md)。当前构建默认版本以 README 与构建脚本为准，以下历史版本和通过数不作为新版本验收。

桌面继续使用 800×600 逻辑场景与 4:3 等比完整显示。宽度较窄但使用鼠标的桌面浏览器仍是桌面模式。自动识别需要触摸能力、粗指针、无悬停能力以及合理的屏幕尺寸；混合设备可用右侧“界面”手动切换。选择保存在当前浏览器，也可临时使用 `?device=mobile`、`?device=desktop` 或 `?device=auto`。

竖屏默认把真实游戏画面按4:3铺满屏幕宽度，控制器放在画面下方；横屏画面在中央按高度尽可能铺满，两侧留出独立控制轨。常见844×390横屏画面为520×390、左右各162px。较短568×320屏为两侧最少72px触控区略减画面至424×318，仍居中。地图内的黑色房屋边缘属于游戏原图，不用拉伸画面抹去。

两种朝向都有八方向摇杆，对应键盘方向键：推向哪边就向哪边走，松开、取消、失焦和旋转立即停止。可同时直接轻点真实游戏画面寻路或操作原按钮。双指在画面中缩放/平移，范围为默认适配的0.5..4倍；“−/＋/复位”提供替代。仅游戏画布变化，菜单/摇杆/鼠标键大小位置不随缩放；“复位”恢复当前朝向的默认等比适配。登录原图的空80/60边框在手机正常登录画面中去除，其余画面保留完整800×600，避免裁掉原生菜单。

登录、选线、建角、状态、背包、宠物、任务、系统、NPC 对话和战斗指令提供可滚动的文字与按钮。按钮最小触摸高度为 44 CSS 像素，原生输入使用至少 16px 字体。原缩略预览已经由可直接操作的真实游戏画面替代。文字面板复用当前可达的原游戏操作，每次点击仍检查画面、对话与原热区，服务端校验和协议不变。横屏左上菜单可滚动、左下摇杆固定，右侧“‹/›”切换当前可达选项并在原画面高亮；“左键”在选中位置执行原鼠标点击，“右键”执行原右键功能（例如取消当前战斗目标、转向、拾取或宠物原确认），不一律冒充返回。还可以轻点原画面确定目标，再使用鼠标键。

长按控制按钮650ms后拖动可调整位置；摇杆需长按静止中心，持续推方向不会变成拖动。拖动期间会停止移动并阻止原按钮激活，已移动控件不会被侧栏裁掉。位置按横竖屏分别保存，重载后恢复；“重置按钮位置”清除自定义位置并恢复默认，和只重置游戏缩放的“复位”不同。第二指介入、取消或失焦会退出位置编辑。默认控件不覆盖游戏；用户主动拖动后可自行选择位置。

“聊天”打开原生输入；点击“发送聊天”或在组合输入结束后按回车提交。输入框复用游戏的原节点，保留密码遮蔽；组合输入期间的按键先由公共输入层拦截业务处理，避免选词回车误发聊天、登录或NPC输入，浏览器的输入法默认行为不被取消。VisualViewport 跟随可见区域变化，软键盘弹出后面板可滚动；全屏面板与模式开关考虑四边安全区。自动化验收覆盖可见区域缩小和合成 composition 事件，具体 iOS/Android 输入法仍需实体设备复核。

手机打开面板、取消或失焦会停止已有寻路和待交互目标；自动遇敌在面板下暂停。交易“返回”会发送原生取消请求，并等待服务端通知双方关闭。桌面模式开关内的按键释放继续传给游戏，避免移动粘键。界面未改变时保留DOM，不逐帧重复写入同一组属性。

手机输出画布最多按 2 倍设备像素、2048×1536 上限渲染，场景内部仍保持 800×600；纹理缓存目标降为 128MiB，桌面维持 512MiB。核心预加载资源与近期正在使用的纹理不会立即强制释放，128MiB 是淘汰目标而非进程总内存硬上限。真实游戏画面取代预览，不再进行每秒15次的缩略图复制。

## 构建与运行

需要 Node.js 24+（内置 TypeScript 类型擦除）与 Go 1.27+。无需安装项目 npm 依赖。

```bash
scripts/build-linux.sh
sha256sum -c bin/saserver.sha256
bin/saserver --version
bin/saserver
```

自定义 Go 路径可用 `GO_BIN=/path/to/go scripts/build-linux.sh`。默认版本 `v0.2.6-LYNX`，目标 Linux AMD64、CGO 关闭。脚本通过本地与CI共用的 `scripts/stage-client.mjs` 准备嵌入内容，再使用 Go embed 打包；生成的嵌入文件不提交 Git。客户端成功转换所有源码后重建专属dist目录，移除废弃模块。嵌入目录只允许README标记、index.html和生成dist；未知文件或符号链接会让发行构建明确失败，避免本地文件被打进二进制。

默认配置 `client: client`、`client: embedded` 或空值选择内嵌页面。明确设为 `client: ./client`、绝对路径或其他自定义目录可用外部页面，便于开发。直接运行 `go build` 但未准备嵌入文件时，HTTP 503 会提示运行完整构建脚本。网页入口仅公开 HTML 和 dist JS，不公开源码、配置、数据库或 source map。

二进制没有内嵌 1.23GB 美术音频和 gamedata。运行需保留资源与配置；资源校验、解压位置见根 README。存档和配置没有迁移步骤，仍由原服务端读取。JS保持no-cache策略，内容未改变时使用ETag返回304；更新二进制后内容摘要改变，浏览器会取得新模块。显式外部目录逐请求重新计算摘要，支持开发热更新。压缩协商尊重gzip;q=0，并为编码变体发送Vary。

Linux停服发送SIGTERM或Ctrl+C，等待“已退出，在线角色位置已保存”日志后再清理运行目录。服务端保留原世界协程与存档队列的排空等待；SIGKILL、断电及强制超时终止仍无法保证内存状态保存。

## 验证与边界

验收使用真实 Chromium + Playwright + CDP 触摸输入、完整官方资源、真实 Go 服务、SQLite 和 WebSocket。登录、注册、建角与游戏操作通过 UI 完成；调试对象仅用于读取状态。测试用 GM 仅在独立临时目录启用，用聊天命令创建物品、宠物和战斗场景，没有写入交付配置或现有数据库。

浏览器模拟能确认界面、网络指令和实际游戏状态，但不替代实体 iPhone/iPad/Android 的 GPU、系统键盘、安全区和 Safari 音频兼容验证。本次没有宣称完整游戏内容、全部职业道具或所有 NPC 分支均经手工验收。本轮横竖屏/摇杆/缩放/控件拖动证据见 `Report/SA-1112-03/ACCEPTANCE.md`；历史发行审查见 `Report/SA-1112-02/ACCEPTANCE.md`，首次适配见 `Report/SA-1112-01/ACCEPTANCE.md`。
