# v0.2.4-LYNX 手机适配

桌面继续使用 800×600 逻辑场景与 4:3 等比完整显示。宽度较窄但使用鼠标的桌面浏览器仍是桌面模式。自动识别需要触摸能力、粗指针、无悬停能力以及合理的屏幕尺寸；混合设备可用右侧“界面”手动切换。选择保存在当前浏览器，也可临时使用 `?device=mobile`、`?device=desktop` 或 `?device=auto`。

手机进入地图后使用人物附近的近景，方向按钮按下行走、松开停止；也可以轻点地图寻路。拖动、多指操作和取消触摸不会生成一次地图点击。双指可以缩放、平移近景，缩放按钮及“复位”提供替代操作。地图边缘的摄像机范围受到约束。

登录、选线、建角、状态、背包、宠物、任务、系统、NPC 对话和战斗指令提供可滚动的文字与按钮。按钮最小触摸高度为 44 CSS 像素，原生输入使用至少 16px 字体。建角保留原游戏画面的只读预览，实际操作使用可读按钮；预览不承担小热区点击。文字面板复用当前可达的原游戏操作，每次点击还会检查画面、对话与原热区，服务端校验和协议不变。

“聊天”打开原生输入；点击“发送聊天”提交。输入框直接复用游戏的原节点，因此原有密码遮蔽、事件与输入法处理继续有效。VisualViewport 跟随可见区域变化；软键盘弹出后面板可滚动。自动化验收覆盖可见区域缩小和合成 composition 事件，具体 iOS/Android 输入法仍需实体设备复核。

手机输出画布最多按 2 倍设备像素、2048×1536 上限渲染，场景内部仍保持 800×600；纹理缓存目标降为 128MiB，桌面维持 512MiB。核心预加载资源与近期正在使用的纹理不会立即强制释放，128MiB 是淘汰目标而非进程总内存硬上限。只读预览最大 400×300 像素、15fps。

## 构建与运行

需要 Node.js 24+（内置 TypeScript 类型擦除）与 Go 1.27+。无需安装项目 npm 依赖。

```bash
scripts/build-linux.sh
sha256sum -c bin/saserver.sha256
bin/saserver --version
bin/saserver
```

自定义 Go 路径可用 `GO_BIN=/path/to/go scripts/build-linux.sh`。默认版本 `v0.2.4-LYNX`，目标 Linux AMD64、CGO 关闭。脚本把构建后的 `client/index.html` 和 `client/dist/*.js` 复制到 `server/webclient/static/` 后使用 Go embed 打包；生成的嵌入文件不提交 Git。

默认配置 `client: client`、`client: embedded` 或空值选择内嵌页面。明确设为 `client: ./client`、绝对路径或其他自定义目录可用外部页面，便于开发。直接运行 `go build` 但未准备嵌入文件时，HTTP 503 会提示运行完整构建脚本。网页入口仅公开 HTML 和 dist JS，不公开源码、配置、数据库或 source map。

二进制没有内嵌 1.23GB 美术音频和 gamedata。运行需保留资源与配置；资源校验、解压位置见根 README。存档和配置没有迁移步骤，仍由原服务端读取。

## 验证与边界

验收使用真实 Chromium + Playwright + CDP 触摸输入、完整官方资源、真实 Go 服务、SQLite 和 WebSocket。登录、注册、建角与游戏操作通过 UI 完成；调试对象仅用于读取状态。测试用 GM 仅在独立临时目录启用，用聊天命令创建物品、宠物和战斗场景，没有写入交付配置或现有数据库。

浏览器模拟能确认界面、网络指令和实际游戏状态，但不替代实体 iPhone/iPad/Android 的 GPU、系统键盘、安全区和 Safari 音频兼容验证。本次没有宣称完整游戏内容、全部职业道具或所有 NPC 分支均经手工验收。详细证据和测试命令见 `Report/SA-1112-01/ACCEPTANCE.md`。
