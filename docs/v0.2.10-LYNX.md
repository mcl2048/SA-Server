# v0.2.10-LYNX · 战斗可读性与挂机策略

本批任务SA-1113-03，接续v0.2.9的多角色后台机制，集中修复战斗显示、倒地状态和自动策略。实现、测试及最终摘要见 [本批验收](../Report/SA-1113-03/ACCEPTANCE.md)。

- 战斗HP/MP放在角色和宠物外形下方，降低遮挡；伤害为黄色粗体描边，位置保持在战斗画面内，覆盖五敌最上方目标。
- 人物、宠物和敌方在HP归零后保持倒地姿态；恢复快照和后续回合继续保持，复活时恢复正常动作。
- PvE人物倒地后，活宠按自身技能、状态、生命和有效敌人独立选择自动行动；倒地不再被当成需要逃跑的低血状态，保护技能避免无效保护尸体。既覆盖单人多宠，也覆盖多人队伍。
- 无前台玩家或观战者的战斗跳过展示协议转换；战斗模拟、自动行动、经验与奖励结算继续执行。重新接入使用实时快照。
- 移动端把摇杆控制区放在游戏下方首位，智能系统按钮列表放在其下方独立滚动；可遇敌野外提供自动遇敌快捷开关，状态由服务端确认。

本版无新增Assets素材，继续使用已有机械宠增量包。PVP和手动战斗保持原命令机制。浏览器验证使用真实Chromium及指定触屏视口，实体设备、Safari、输入法和生产容量不在认证范围；微基准结果不能换算为整服并发承诺。
