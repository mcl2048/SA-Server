# v0.2.20-LYNX · 宠物仓库与培养

任务SA-1115-02，基线4751c2b / v0.2.19-LYNX。验证证据和进度见 `Report/SA-1115-02/`。

## 使用

宠物仓库总容量增加到500只，与转生次数无关。寄放与培养从随身五槽选择；仓库领取每页5只，显示页码、已用容量及培养状态，通过上一页/下一页查看。培养和普通寄放共用500容量。

所有宠物店新增培养及领取路径，包括原先只卖宠物的店。培养按确认执行时的“人物当前等级＋宠物当前等级”×100收取一次费用，确认后宠物离开随身栏并存入仓库。每只培养宠物在人物实际获得战斗经验时，另得该经验的80%（向下取整）并按原有成长规则自动升级；普通寄放宠物不获经验。领取后停止培养，重新普通寄放也不会继续。
