# v0.2.14-LYNX · 自动恢复与幽风伙伴莉莉丝

本版对应 SA-1114-03，基线 `256f7ab / v0.2.13-LYNX`。

## 战斗状态

反击现在重新检查行动者当前能否行动；麻痹、石化、魔障、晕眩和未被伤害唤醒的睡眠不会绕过回合状态检查。睡眠被有效伤害唤醒后的反击仍遵循原生规则。HP0、击飞、逃跑的既有离场边界继续有效，普通倒地可明确复活，击飞不能在本场复活。

到期异常仍消耗最后一次不能行动的回合，但后续 Stun 事件发送当前已解除状态，避免画面重现旧图标。

## 自动恢复

- “补血时机”采用严格低于所设百分比，0关闭阈值触发。人物、在场宠物和仍骑乘的坐骑都按各自耐久比例检查。
- 按受伤程度尝试实际可治疗的对象；一个无法被自身精灵治疗的宠物不再挡住人物自愈。
- 优先使用战斗可用、能够施放且估算浪费较少的恢复精灵，再用肉及其他有效耐久恢复品；沉默时跳过无法施放的恢复精灵。
- 补气判断考虑当前受伤对象能够使用的精灵与实际 MP 成本，不以无关的便宜自身精灵阻止宠物恢复。气力不足时使用有效气力药，下一次回合继续治疗。
- 战斗对混合料理采用原生“体优先，否则气”语义；带有耐久效果的料理不被当作气力药，无效果道具不自动消耗。
- 自动与快速使用同一服务端权威策略；桌面和移动设置同步相同阈值。客户端回退策略补齐两种恢复精灵、排除“气绝回复”误识别，并在没有活敌时防御。

## 移动与发行

保留原生移动全屏窗口重排、按钮缩放、全屏行走／战斗禁双指缩放和转屏镜头锁定。新增素材仅通过独立莉莉丝补丁发布；Assets 原树、运行数据库和凭据不进入仓库或发行包。

使用 `scripts/build-linux.sh` 生成匹配客户端及静态 Linux AMD64 程序；`scripts/package-linux.py` 生成完整替换 ZIP。实际测试、摘要和截图见 [验收报告](../Report/SA-1114-03/ACCEPTANCE.md)。浏览器触屏/尺寸模拟不能代替实体 Android/iOS 或 Safari 认证。

## 莉莉丝

- 形象199200；风80、火20。参考原图透明提取、八向位图动作；站立兔耳轻动、离地浮行，普通攻击沿原生移动到敌人面前并双手释放蓝紫能量，幽灵风暴原地施法。
- 尺寸以雷龙系（布拉奇多斯，原生素材编号100353）为参照，主体高度约为常态雷龙的2/3；160×160帧格包含透明余量，不能把帧格高度当作主体尺寸。动作帧保持同一尺度。
- 与佩露夏同档：初始成长次数40、每级实际成长次数4、总基础预算149；体/腕/耐/敏为27/57/17/48，牺牲耐久和防守换取攻击与速度。原生文本4.50按既有整数读取行为为4，未改变全部旧宠成长规则。
- 分布在吉鲁岛·幽风林缘（地图300，470,230附近独立小区域）；保留原敌群70%权重，幼体Lv1占12%，巡游体Lv44–48占18%。沿用原生捕获、等级和空位约束。
- 幽灵风暴（29040）：敌方全体各按原生物理伤害结算的75%，不反击；使用正常防御、光镜守、闪避、守护者及坐骑分摊。正伤害命中且目标仍活着、无其他异常时，有35%–80%概率石化3次行动。概率为 `clamp(55 + (施法等级−目标等级)/2 − max(0,石化抗性), 35, 80)`；整数除法遵循Go向零截断。
- 敌半场幽蓝火焰含三枚骷髅轮廓，原生RGBA动画199201，28帧×3ticks。群体效果每侧只播放一次；快速战斗保持同一权威结算。
- 原生宠物详情、GM目录及相簿追加独立条目和完整故事；既有四宠相簿位置与数据源保持稳定。

### 素材安装

```bash
bash update/install-lilith.sh
# 自定义素材路径：
bash update/install-lilith.sh --assets /srv/stoneage/Assets
```

需要Linux、Bash、Python3.9+。5个文件（2张RGBA图集、2份动画JSON、1份manifest）仅安装到 `extensions/lilith-v1/`，逐文件SHA校验、原子发布、幂等并保留冲突原文件。详见 [增量包说明](../update/README.md)。缺包时使用原资源回退形象/火焰，不影响战斗逻辑。

美术制作实际使用用户原JPG及Pillow/NumPy进行去棋盘、分层变形和位图绘制；当前会话无图像生成工具，未调用图像生成API。原图与可复现生成脚本留存，动画预览见报告，不将程序绘制素材声称为AI重绘。
