# v0.2.18-LYNX · 四宠贴地阴影与双爪转向／跑姿

萨鲁法斯的横向视图曾因最长边限制而整体缩小；现按主体高度等比例校准，保留八向骨架，扩大逻辑帧以容纳长侧面。奔跑采用前后腿组的蹬地、屈膝收腿、前伸落脚和躯干俯仰，参考金格萨贝鲁，不再只是四根腿摆动。克劳德斯也校准八向体积。两宠新增固定地面阴影，跳起或受击时不随身体升空／旋转。

莉莉丝与Lisarido追加独立地面阴影；漂浮与贴地角色各自保持合适的足底／地面关系，并修整边缘与锚点。

素材目录为`primal-claws-v3`、`lilith-v2`、`lisarido-v2`。各安装器先完整校验并安装新版，再按旧发行清单自动删除已知旧包，已有新版也会清理旧残留。未知文件／目录、被修改文件或链接保留并报错。基础素材和其他扩展不进入清理范围。

```bash
bash update/install-primal-claws.sh
bash update/install-lilith.sh
bash update/install-lisarido.sh
# 自定义素材目录时分别附加 --assets /实际路径/Assets
```

必须同步更新匹配`bin/saserver`，使用外部client路径时同步新客户端。正常停服存档后重启并刷新网页，确认浏览器请求新版目录。删除旧目录不会使旧程序自动改用新包。脚本只处理素材，不停止用户服务。

宠物／动作／技能编号、成长数值、技能规则和存档兼容；移动原生UI、按钮缩放、禁双指缩放保持。截图复核、连续动作、阴影、安装与真实浏览器证据见[本轮报告](../Report/SA-1114-05-angle-followup/index.html)。移动为Chromium触屏视口模拟，不冒充实体设备认证。
