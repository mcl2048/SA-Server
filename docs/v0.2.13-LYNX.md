# v0.2.13-LYNX · 移动全屏原生交互与镜头

SA-1114-02，基线 `b8e8195 / v0.2.12-LYNX`。

## 原生窗口

- 宠物初开只列基本信息，点名字进入原生详情；动态图使用原动作 ticks、帧与偏移，换宠/关窗/切屏不恢复旧动画。最多缓存两个动作，每动作最多 32 张有界帧，静态头像最多 12 张，图集始终串行解码；减少动态效果时显示固定姿态。
- 人物状态使用 `Status.face` 原头像；体力、腕力、耐力、敏捷旁显示 +1。每次进入原 `StatUp`，服务端确认数值与点数，耗尽时移除加点入口。详情展开与队伍页仍遵循桌面逻辑。
- 道具图片来自实际 `InvItem.image`；人物装备含头槽 0，宠物装备按原 type 范围，可用性与场景/目标来自协议字段。可执行动作在卡片下明确显示“装备／使用／卸下”；恢复道具仍选自己/宠物/队友再提交，非可用物品不显示虚构使用按钮。标题图片继续保留原拿起/移动操作。

按钮由当前窗口注册的原生热区派生，仍经过主输入层场景与模态检查。经典手机与桌面保留各自原操作。

## 缩放与锁定

用户补充要求：移动全屏行走及战斗取消双指缩放和平移，仅使用按钮缩放；修正竖屏及横转竖镜头锁定。具体几何与实际验证见验收报告。经典手机手势继续可用。

## 交付

`bin/saserver`、SHA-256 和 `saserver-v0.2.13-LYNX-linux-amd64.zip` 使用匹配客户端构建；ZIP 排除原 Assets、运行数据库与凭据。无素材追加，继续沿用原机械宠增量包。验证范围、实际 Chromium 截图与未认证设备见 [验收报告](../Report/SA-1114-02/ACCEPTANCE.md)。
