# v0.2.12-LYNX · 战斗离场语义与手机屏内全屏UI

本批任务 SA-1114-01，发行基线 `1c5bd7f / v0.2.11-LYNX`。

## 战斗规则

HP≤0立即表示该人物/宠物/敌人倒地，不能行动或成为普通攻击的有效目标；普通倒地只有明确复活才能恢复行动。击飞和逃跑均是本场永久离场，不能由敌人复活、咒术或道具召回。仍在场的队友与活宠继续各自回合，某一方全部无有效单位时结算。

修复的服务端链路是“我方击飞敌人→较慢的敌人复活它→原行动队列又让它攻击”；客户端已移除模型，因此也可能出现空位伤害。统一存活/复活目标过滤，并重置合法复活的击杀归属。客户端通过HP赋值同步死亡状态，补齐剧毒死亡；已飞走目标拒绝迟到的命中与复活显示。普通、自动与快速使用同一套规则。

## 手机全屏

选择“界面→游戏画面→全屏游戏界面”。地图、战斗、NPC、各类菜单、登录与提示都使用同一个设备视口；打开面板不会退回4:3网页侧栏。

屏内窗口复用原游戏九宫格和菜单/战斗图标，触控按钮保留原生动作ID。竖屏以完整可滚动面板显示信息和指令；横屏较宽时分列信息与指令，短屏继续可滚动。真实输入框、返回、目标选择、摇杆释放及安全区约束继续生效。原生全屏请求受浏览器能力限制，不能支持的平台仍铺满可见网页窗口。桌面显示分支冻结，经典手机模式继续可选。

背包按当前原生装备/背包槽位排成触控图格，保留真实道具CG、数量、说明和同一套选取/使用操作；宠物以每只宠物的等级、HP、状态和原生状态/详情按钮组成卡片，详情展示原素材模型。地图复用游戏本来绘制的底图/标记图层，精确轻点进入原生寻路，拖动进入原生平移；取消和窗口切换清理输入，拖动不会变成误寻路。模型预览使用稳定静态姿态，战斗与桌面原动画路径保持原样。

无新增Assets；皮肤在运行时读取既有素材并缓存，解码单任务串行，避免每帧并发解压图集。
