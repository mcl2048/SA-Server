# v0.2.17-LYNX · 双爪宠物战场素材修整

基线：e5aa5d331ac5f50981948206a9d93917a8b49d7b，承接SA-1114-05。

修复萨鲁法斯／克劳德斯侧面和战场比例：旧生成器将原图强制匹配不同姿态的参考外框，虎的常用西北／东南方向横向相对纵向仅0.501／0.512。新版按单一比例缩放，虎包络112×84、蟹118×92原生像素；参考金格萨贝鲁与洛奇安的整体体型，保留上传原图的骨架比例。不同姿态不会强制获得相同的外框宽高。足底锚点保持在原生站位附近，排除尾巴／红爪对身体中心的干扰。

站起扫击改用髋部支点和原图纹理连接支撑腿，足底保持着地；移除粗线／圆圈替代关节。收敛步态及尾巴摆幅，清理分层旋转碎片，缩小后轻度提亮金属中间调及锐化，保留八向原图、左红爪、扫击／跳刺、红痕和原生出击回位。每宠仍为376帧／64动作，共用24帧特效。

## 安装

更新匹配的Linux AMD64程序及客户端后执行：

```bash
bash update/install-primal-claws.sh
# 使用自定义素材根目录时：
bash update/install-primal-claws.sh --assets /srv/stoneage/Assets
```

新图包为`extensions/primal-claws-v2/`，只含manifest、3图集、3动画JSON，共7文件。v2旁装，保留旧v1目录；宠物199400／199401、特效199402与图像范围不变，存档无需迁移。只装v2但继续使用v0.2.16程序不会切换素材。安装器先校验再原子发布，重复安装幂等，未知冲突保留。正常保存停服后更换程序、重启并刷新网页。其余三个扩展包照常安装。

技能的80%普通命中、自身一次30%–60%防御5回合、特殊伤害／猛毒、实际总伤害1.8%自疗，以及洞窟非1级仅攻击／防御均沿用v0.2.16规则。移动设备原生全屏UI、按钮缩放与禁双指缩放继续保留。待机镜头按人物及出战宠物的真实绘制外框取景，解决横屏转竖屏时宽宠左侧裁切；播放期保持执行者跟随。
