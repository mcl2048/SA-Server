# v0.2.21-LYNX · SA-1115-03

本版优化挂机的资源消耗与续航，并让小地图列出当前地图的实际入口，可点击行走进入洞窟、村庄。

## 使用与行为

- 在系统→AI设置开启自动遇敌和自动／快速战斗；补血阈值也用于野外整备。补给取背包原生可用物品，肉优先，先人物HP、参与宠物HP、再人物MP，每秒最多一件。只处理出战／待命／骑乘中的存活宠，不处理休息或寄放宠；没有新增野外自动精灵施法。
- AI设置或其他前景窗口、交易等事务暂停整备与移动。换图、手动移动按既有规则停止遇敌；缺少补给且人物HP≤20%时停止。恢复阈值0禁用恢复。
- 优先逃跑、危险逃跑和捕获无目标逃跑共用每场三次真实失败上限；达到后回到普通策略。显式逃跑时存活主宠防御。
- 浏览器冻结或关闭后服务器继续执行同一战斗、资源消耗、奖励、培养与保存；重新登录原生接管恢复当前状态。服务重启会清除挂机意图／恢复令牌，不补算停服收益。
- 小地图左栏默认“本区地点”，每页9处，“区域”保留历史浏览。来自实际可走跨图入口，条件入口标记※，到达后由服务器检查任务资格；列表不授予通过条件。多格入口保留全部坐标，自动选择可达边缘。
- 目标块、起终点走廊优先加载，找不到路线时逐渐扩大至全图。未知格始终不可走，不穿墙角和非目标传送点。快速战斗暂停并恢复路线，手动输入仍取消。

## 性能与验证依据

隔离微基准：自动决策448B／5次分配→0B／0次；状态、满45格背包、5宠及战前展示组合，在离线状态约88KB／1064次→0B／0次。在线展示保持原内容。只优化没有接收者的投影，结算和保存仍走权威路径；不是整服吞吐或内存比例保证。

本轮新增三失败边界、原生HP／MP与参与宠物补给、编辑租约／事务／换图、离线任务与在线队友状态回归，并增加真实子进程／WebSocket／SQLite的离线SIGTERM存档验收。最终测试、真实Chromium桌面与移动证据、寻路差分／基准、HTTP字节一致性和发行摘要见[最终报告](../Report/SA-1115-03/index.html)与[验收](../Report/SA-1115-03/ACCEPTANCE.md)。移动使用Chromium触屏和视口模拟，未认证实体Android／iOS／Safari。

## 升级

完整包为 `bin/saserver-v0.2.21-LYNX-linux-amd64.zip`，`bin/saserver`为匹配的静态Linux AMD64程序。先备份数据库和配置，正常SIGTERM存档停服；替换程序，使用外部客户端时同步本版客户端，再启动并刷新网页。默认内嵌客户端已包含在程序内。没有新增Assets、独立素材升级包或数据库结构迁移；完整ZIP沿用已有素材增量安装器，原Assets树、测试数据库和凭据不入Git。

研究只参考公开SaSH的等待／阈值／肉优先策略，未复制、运行或分发其实现；数值和实际物品效果仍依据本项目原生规则。来源、微基准范围和保留的中间失败见报告。

本轮另按用户确认提交现有config.yaml并放入ZIP：minimapReveal=1、maxChars=4、charMaxTrans=7、expRate=1.2、dropRate=1.3、encounterRate=1.5、battleSpeed=1.6、enemyGuardRate=0.7、groundPet=60。它们是公开运行配置的调整，未改代码的默认回退／范围校验；已有自定义配置请按需保留。
