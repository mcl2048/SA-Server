# v0.2.8-LYNX：四位机械伙伴

本版在独立成长配置、五宠出战、持续挂机和新登录封面基础上，加入四只可自然遇敌、捕获、养成、拍照和参战的机械宠物。名称分别呼应 OpenAI、Claude、Grok 和 Gemini；造型与故事属于本项目的原创角色设计，用来表达对观察协作、审慎照护、好奇探索、双核并行的印象，不构成模型能力排名。

## 设计与数值

四宠参照原帖拉所伊朵的钢甲、铆钉、硬边高光和Q版比例：八方向、粗外轮廓、分块赛璐璐明暗，不依赖现代3D材质。原机暴成长分配为体23/腕35/耐25/敏21，总104；新四宠同样总104、初始成长次数28、每级成长次数4，六技能栏。不会通过同时提高所有能力成为无代价的上位替代。

四宠均自带攻击、防御和一项专属技能，剩余技能栏按原学习规则使用。成长分配是生成成长的输入，不是保证某只捕获个体的最终攻击/防御；宠物档次、随机成长、等级、转生和配置仍然生效。

吉米奈采用用户给出的双核迅猛龙方向。为保持现有战斗体系与平衡，本版将“两次高速突袭”落实为原生两连，**没有实现额外破盾或必定暴击**，不把概念描述当作实际效果。奥普埃使用的原增益机制以基础防御计算命中/闪避中的敏捷增量，不改变出手顺序，也不叠加已有同类效果；界面技能说明与实际行为保持一致。

## 增量素材部署

基础资源仍使用 `/home/coder/TMP/assets-v0.2.3.zip` 对应的官方资源包；它和展开后的 `assets/`、`Assets/` 均不上传Git。本版只提交新增机械宠素材压缩包、校验清单、生成源码和安装脚本。

在服务器拉取本次源码后执行：

```bash
git pull
cd update
bash install-ai-pets.sh
```

自定义素材目录时按 [update/README.md](../update/README.md) 指定 `--assets`。安装器校验整个压缩包及每个文件，拒绝路径穿越、符号链接、未知文件和冲突内容，只安装 `extensions/ai-pets-v1/`，不修改原 `manifest.json`、`index.bin.gz`、图集或音频。相同内容可重复执行；不同内容的既有扩展会明确报错并保留原文件，不静默强制覆盖。

服务器不读取新PNG来初始化宠物逻辑，缺少新增素材不会阻止服务启动。客户端对这套扩展实行整体校验和原子启用：缺包、不完整、损坏或超时就退回官方资源中确实存在的机暴动画，宠物名称、数值和操作仍正常。安装后重新加载网页启用新形象。基础资源整体缺失时，服务器仍可启动，但浏览器原有游戏画面本身需要基础资源才能显示。

## 构建与验收

`scripts/build-linux.sh` 默认生成 `v0.2.8-LYNX`，先从服务端内嵌JSON同步客户端图鉴，再构建网页并内嵌到Linux AMD64二进制；四宠逻辑与分布随二进制提供，不要求手工修改旧GBK游戏数据表。新PNG保持外部增量安装，避免把完整素材包塞入二进制。
