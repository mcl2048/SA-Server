# SA-1115-01 / 雷萨利朵炮臂动作

- 基线：v0.2.18-LYNX，生成器 `scripts/generate-lisarido.py`，图包 lisarido-v2。
- 根因：旧实现仅以火炮重心旋转 ±13°、向上平移 5px，右手与肩关节未形成抬臂动作；枪口闪光由另一个猜测向量生成，部分方向脱离实际炮口。旧棕色色键还包含背面金发、裙摆描边及脚。

- 保持：232角色帧、24电磁特效帧、64角色动作、图像编号/矩形/锚点、动作方向/时长/事件合同。120待机/行走/受击/死亡/防守帧与v2逐字节相同；112攻击/HAND/throw帧使用新的局部炮臂姿态，独立电磁特效PNG逐字节不变。
