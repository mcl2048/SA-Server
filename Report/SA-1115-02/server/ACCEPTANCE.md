# SA-1115-02 · 服务端验收

普通寄放和付费培养共用 500 格宠物池，未转生角色同样可用。领取按真实数量每页五只，500 只共100页；原生身上宠物选择器完整呈现五个携带槽。两类 PetShop 都提供培养与领取，旧出售菜单索引保留。

培养确认时收费 `(人物当前等级+宠物当前等级)*100`。每只正在培养的宠物独立获得人物本场实际所得经验向下取整的80%，不分摊、不减少人物经验，自动套用原生成长和等级上限。普通寄放不获得培养经验，领取立即停止培养。培养标记使用兼容旧存档的可选 JSON 字段，余额和宠物状态沿用同条角色更新保存。

常驻测试覆盖500／501边界、末页第五只、伪造翻页和跨页／畸形行号；两类店铺培养、取消、精确费用、重复确认、SQLite持久化和领取停止培养；余额不足、骑乘、送信、家族守护、池满、战斗、交易与摆摊八项限制。窗口绑定选中的宠物对象；槽位被替换时拒绝操作新对象，报价后等级变化则要求重新确认。旧溢金出售的二次确认也通过回归。

两位队员各有两只培养宠，在共享经验开关两种配置中，人物基础127经验经2倍规则与1.5倍智慧得到381，每只培养宠独立得到304，普通寄放宠为0。真实自动、快速和离线自动路径重复20次tick，只结算一次、每只得到101。死亡、逃跑、失败和PvP不凭空增加经验；非战斗人物加经验不触发培养，1经验向下取整为0，模板等级上限保留剩余经验。

HTTP和停服只读审查没有发现需要在本轮另改的P0/P1：此次不新增路由；发行文件边界、gzip、禁目录列表和世界／家族／HTTP存档结束顺序沿用现有测试。培养无轮询、无新goroutine／定时器，不把500只宠物全量发给客户端，每页只发送五行；成长收益聚合后统一提交家族快照。

本子任务未修改素材、数据库或生产实例。移动设备认证范围由真实浏览器报告限定，不将 Chromium 触屏／视口模拟表述为实体手机验证。
