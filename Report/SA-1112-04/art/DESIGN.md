# StoneAge · Return of the Heroes 登录封面

本图是本地原创SVG绘制后由Chromium渲染的PNG，没有使用外部图像生成模型，没有使用官方游戏资产或网上素材。人物、幼龙、三角龙、翼龙、岛屿、瀑布、石像、热带叶片与标志细节全部保留为SVG图形，便于继续修改。

## 最终产物

- `client/art/login.png`：1280×960，完整4:3封面。运行时建议直接加载此PNG，不需要字体、SVG或额外依赖。
- `client/art/login.svg`：完整可编辑原画；`viewBox="0 0 800 600"`，内嵌DejaVu Sans Bold字体，使两个英文标题在其他设备打开时仍一致。SVG元数据中保留完整字体许可。
- `client/art/FONT-LICENSE.txt`：DejaVu/Bitstream Vera字体许可。DejaVu修改为公有领域，原Bitstream版权与许可按要求随源码保留。
- `Report/SA-1112-04/art/generate_login.py`：原画生成与渲染脚本，只依赖现有Python、Playwright/Chromium和系统DejaVu字体，不安装新库。
- `Report/SA-1112-04/art/login-form-preview.png`：独立表单叠加构图预览，仅供界面实施参考；账号框、按钮、中文标题没有烙进最终封面。
- `Report/SA-1112-04/art/preview_login.py`：构图预览脚本，不修改游戏或实现真实登录行为。

## 构图与视觉

浅金石刻式StoneAge主标题位于左上，英文副标题为准确的 `Return of the Heroes`。浅色标题、深玉绿描边和轻微倾斜呼应卡通冒险游戏；标题边缘的小缺口与双层阴影提供石质感，而没有把字做成难以辨认的图案。

左侧前景是红发年轻英雄、戴冒险围巾的圆润绿色幼龙，以及闭眼微笑的三角龙幼仔。暖阳和海岛瀑布提供轻松的探索感；中景石像、翼龙、木杆石矛和背包补足原始世界题材。前景植被形成天然框景，整体采用玉绿、海蓝、浅金与暖棕，和已有手机控制器配色兼容。

右侧暗森林是刻意保留的交互静区，树干与微弱萤火提供深度，避免把UI区域画成空白色块。最终图不包含假输入框，真实游戏仍使用原输入节点、焦点与业务事件。

## 推荐游戏集成坐标（800×600逻辑）

完整封面覆盖x0..800/y0..600，此轮应关闭旧登录美术的80/60裁切。PNG像素坐标等于下列数值乘1.6。

| 元素 | 逻辑位置/尺寸 | 建议样式 |
|---|---|---|
| 半透明卡片 | x478 y198 w266 h313 | 深玉绿，20px圆角，轻金绿边框 |
| 小英文引导 | x500 y210 | 8px，宽字距，淡绿 |
| 欢迎归来 | x500 y228 | 24px，浅金 |
| 新的冒险，正在等你 | x500 y259 | 10px，浅绿 |
| 账号输入 | x500 y278 w220 h38 | 真正原生InputBox，深色底，placeholder账号、aria-label账号 |
| 密码标签 | x500 y333 | 10px，浅金绿 |
| 密码输入 | x500 y350 w220 h38 | 原生密码输入，不烙图 |
| 进入游戏 | x500 y410 w220 h44 | 暖金主按钮，深绿文字 |
| 注册 / 清空 / 找回 | x500..720 y475 | 次级操作，避免与主按钮竞争 |

右侧卡片不遮挡人物、恐龙或石矛。原画左半部的信息足够在手机全宽显示时传达主题；手机可读输入区应继续沿用原移动shell，而不是把桌面小文字放大冒充手机交互。手机画面保持完整4:3等比，不裁标题或恐龙。

## 实际检查

使用真实Chromium把独立SVG渲染为1280×960 PNG，然后通过图像工具实际查看；确认英文单词准确、没有乱码，角色表情与层次清楚，右侧有足够留白。另生成同尺寸中文表单预览并实际查看，确认与拟定输入坐标一致且不遮挡角色。图片尺寸、格式、标题文本及摘要记录在 `validation.json`。

本子任务只创建新美术、脚本与说明，没有修改已有TS、登录逻辑、HTML或构建/服务端文件。HTTP公开路径、内嵌白名单、WebGL画面加载与真实表单的最终端到端验证由主任务完成。表单预览本身不代表真实登录已验收。
